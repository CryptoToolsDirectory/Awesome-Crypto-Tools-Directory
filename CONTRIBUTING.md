# Contributing

This list is a short directory of crypto tools and products. A good row is a real product people can open and use. A bad row is an affiliate dump, a paid-signal funnel, or a dead link.

## Add a tool

1. Fork [Awesome-Crypto-Tools-Directory](https://github.com/CryptoToolsDirectory/Awesome-Crypto-Tools-Directory).
2. Edit `README.md`. Put the tool in the category it actually belongs in.
3. One tool per pull request.
4. Use the same table columns as that section. Do not invent a new table shape.
5. Link the tool’s own site, or its page on [Crypto Tools Directory](https://cryptotoolsdirectory.com/) if it already has one.
6. Open a pull request. In the description, say what the tool does and which section you edited.

Example (match the columns of the section you are editing):

| [Name](https://example.com/) | 8.5 /10 | Type | What you actually open it for | Short feature list |

Scores already on the directory can be copied from that listing. If the tool is not scored yet, leave the score cell empty and say so in the pull request. Do not invent a high score.

## List it on Crypto Tools Directory

A GitHub row and a directory listing are two different things. Do both.

1. Submit the tool or product at [cryptotoolsdirectory.com](https://cryptotoolsdirectory.com/).
2. Keep the name, URL, and category the same as the pull request.

The [featured table](README.md#-featured-tools--products) is separate. A tool can appear there only after it is submitted on the directory and verified. Verified listings stay featured for 30 days, then they rotate out. A pull request alone does not put a product in that table.

## What gets merged

- a real crypto tool or product that still works
- a working URL
- a row in an existing category, with the same columns
- a short note on what the tool is for
- one tool per pull request

## What gets closed

- referral codes, invite links sold as access, paid Telegram VIP, copy-trading funnels
- “star for airdrop,” paid stars, or any reward for GitHub engagement (GitHub does not allow inauthentic engagement)
- duplicate rows, dead links, or a tool that is already listed
- books, newsletters, podcasts, and social accounts with no product. Those belong in [Awesome Crypto Trading Sources](https://github.com/CryptoToolsDirectory/Awesome-Crypto-Trading-Sources)
- long reviews. Those belong on cryptotoolsdirectory.com

## Fix a row

Open an issue or a pull request if a link 404s, a product shut down, or a score is wrong. Say what broke and what you want instead.

## Stars

If the list helped, star the repo. A star is a bookmark for other readers. It is not required to contribute, and it does not unlock a listing, a feature slot, or a score.
